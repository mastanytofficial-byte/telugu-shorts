# Romantic BGM

Put only music you are legally allowed to use here.

Recommended: download a track from **YouTube Studio → Audio Library** and choose a track with **Attribution not required** when possible. YouTube says Audio Library tracks are copyright-safe and can be used in monetized videos.

For automatic mood selection, useful filename keywords are:
- `romance`
- `love`
- `soft`
- `piano`
- `nostalgia`
- `melancholy`
- `sad`
- `hope`
- `uplifting`

Example: `soft-romance-piano.mp3`

Do not put movie BGM, film songs, or other copyrighted music here unless you have the necessary rights/license.
